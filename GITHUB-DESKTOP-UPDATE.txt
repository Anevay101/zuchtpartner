2. GitHub Desktop öffnen und das bestehende zuchtpartner-Repository auswählen.
3. Repository → Show in Explorer.
4. Den versteckten Ordner .git im bestehenden Repository NICHT löschen.
5. Die bisherigen veröffentlichten Projektdateien/-ordner ersetzen.
6. Den INHALT der entpackten V54.0.88-ZIP direkt in den Repository-Ordner kopieren.
7. Unter Changes prüfen, dass keine private JSON-Datensicherung enthalten ist.
8. Empfohlene Commit-Nachricht: „MDR V54.0.88 ZG-/Breeding-Club-Abgleich“.
9. Commit to main und anschließend Push origin.
10. GitHub Pages kurz deployen lassen und die Seite danach mit Strg+F5 neu laden.
