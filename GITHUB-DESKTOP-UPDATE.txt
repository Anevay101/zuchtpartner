MDR-Datenbank V54.0.26 – Update mit GitHub Desktop

1. zuchtpartner-main-V54.0.26-clean.zip entpacken.
2. GitHub Desktop öffnen und das bestehende zuchtpartner-Repository auswählen.
3. Repository → Show in Explorer.
4. Den versteckten Ordner .git NICHT löschen.
5. Im Repository alle übrigen bisherigen Projektdateien/-ordner löschen.
6. Den INHALT des entpackten Ordners zuchtpartner-main-V54.0.26-clean direkt in den Repository-Ordner kopieren.
7. In GitHub Desktop unter Changes kurz kontrollieren, dass keine private JSON-Datensicherung enthalten ist.
8. Empfohlene Commit-Nachricht: „MDR V54.0.26 Zuchtschau-Tab + automatische Modellwahl“.
9. Commit to main und anschließend Push origin.
10. GitHub Pages kurz deployen lassen und die Seite danach mit Strg+F5 neu laden.
11. In VERSION.txt muss „MDR-Datenbank V54.0.26“ stehen.

ZS in dieser Version:
- ZS-Gesamtwert, Grundwert, damaliger Turnierbonus, Cupbonus und Snapshot-Datum stehen im eigenen Pferde-Reiter „Zuchtschau“.
- Die kompakte ZS-Prognose bleibt unter Stammdaten.
- Ext und Ext% bleiben in jeder getesteten Modellvariante getrennt enthalten.
- Mehrere Modelle werden automatisch per Kreuzvalidierung verglichen; das Modell mit dem niedrigsten RMSE wird verwendet.
- MAE, RMSE, R², Spearman-Rangkorrelation und der vollständige Modellvergleich sind im Turnierplaner sichtbar.
